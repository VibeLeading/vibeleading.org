00 · Agent Quick Start

Paste this into your AI agent to set up VibeLeading

Works in OpenCode, Claude Code, Cursor, Codex, and any agent that supports npx skills and MCP servers. 

Give me the Vibe Leading methodology: install the 5 agent skills so I can lead AI agents by intent + real-time telemetry, and add the 4 MCP servers so I get hands in the corporate engine.

SKILLS (npx skills add):
npx skills add VibeLeading/mission-script VibeLeading/ira-prompting VibeLeading/hud-setup VibeLeading/pit-stop-audit VibeLeading/org-geometry

MCP SERVERS (@vibeleading scope, add to MCP config):
@vibeleading/mcp-hybrid-data-engine
@vibeleading/mcp-document-architect
@vibeleading/mcp-real-time-scout
@vibeleading/mcp-privacy-shield

ENV VARS:
MCP_STONE_PATH=data/stone.db
MCP_LIGHT_PATH=data/light.json
MCP_FLOW_PATH=data/flow.json
MCP_DOCS_ROOT=~/.vlb-docs
MCP_SHIELD_NAMES=1

The agent will run the installs and write the MCP config (e.g. .mcp.json for OpenCode, claude_desktop_config.json for Claude Desktop). Restart the agent after it finishes.

01 · The Methodology

From status meetings to a cockpit

Vibe Leading replaces the analog management stack — meetings, vertical reports, middle-managers-as-translators — with a telemetry-driven cockpit built for the race against machines.

◈

The Vibe

The leader's high-frequency strategic intent, written as a Mission Script with the poetic clarity a human feels and the engineering precision an AI can execute. AI is a massive amplifier: a blurry intent becomes a hallucination; a sharp intent becomes an advantage.

◎

IRA — Intent-Result Alignment

The primary HUD metric. How closely the machine's output matches the Mission Script. 100% means the agents delivered exactly what was intended. 60% means the car is sliding off the track.

▤

The HUD

A live scoreboard that replaces the status meeting. The Pilot reads telemetry — Traction, Circuit Delta, Hallucination Debt — instead of asking humans what happened yesterday. Green telemetry cancels the meeting.

◇

Organizational Geometry

The 5-Person Racing Squad: 1 Pilot + 4 Specialists + 100+ NPC Agents. A diamond, not a pyramid. Cut the drag, trust the geometry.

⚒

The Double Tenaza

The two-handed grip. One hand on human intuition, one on machine precision. When you grip both, you stop being a manager — you become a Pilot.

▣

The Garage

The unified engine bay where agents connect directly to corporate data through MCP servers. No human middleman. Build the Garage or stay in the museum.

07 · Frequently asked questions

Answers before you ask the machine

What is Vibe Leading?

Vibe Leading is a corporate methodology for the AI era: one Pilot leads a grid of AI agents and specialist squad members by intent and real-time telemetry instead of by command and meetings.

What is an Intent-Result Alignment (IRA)?

IRA is the core prompt discipline of Vibe Leading: every prompt expresses the Leader's Intent, the Agent's Role, and the Acceptance criteria for the Result. High IRA produces predictable, high-score agent output.

What is the Circuit Delta?

The Circuit Delta measures the gap between the intended outcome and the delivered outcome of an AI assignment. It is the scoreboard that tells the Pilot when the circuit is in tune and when a pit stop is needed.

Are the skills and MCP servers open source?

Yes. All VibeLeading skills and MCP servers are MIT-licensed and public on GitHub under the VibeLeading account.

Do I need to read the book to use the tools?

No. The skills install with npx skills add VibeLeading/<name> and the MCP servers run with npx — each repository has its own README and docs. The book goes deeper into the method and the mindset.
